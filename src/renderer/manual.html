Astuce générale : presque tout a un clic droit (pads, hot cues, morceaux, playlists, en-têtes de colonnes, forme d'onde) et une bulle d'aide quand tu laisses la souris dessus.

La barre du haut

À gauche : mode et disposition
  • PERFORMANCE / LIBRARY : PERFORMANCE pour mixer (decks et navigateur), LIBRARY pour ranger ta collection (navigateur en grand).
  • 2 decks / 4 decks : nombre de decks affichés.
  • Navigateur plein écran (touche Espace) : agrandit la liste des morceaux, les decks continuent de jouer.
Au centre : panneaux et outils
  • FX : affiche la barre Beat FX. MIXER : affiche la table de mixage entre les decks.
  • SAMPLER : les 16 cases de sampler sous les decks (détails).
  • PADS : le sampler 64 pads, l'instrument et le light show. Ouvert, il prend la place du navigateur (détails).
  • MIX POINT LINK : quand un deck atteint son MIX OUT, l'autre deck démarre de son MIX IN, calé.
  • AUTOMIX (menu) : Start Automix with the current list / Stop Automix, Crossfade length (en temps), Repeat, Shuffle.
  • DOWNLOAD : la fenêtre de téléchargement (détails). La pastille compte les nouvelles sorties de tes chaînes suivies.
  • REC : enregistre la sortie master en WAV ; le compteur affiche la durée.
À droite : état et réglages
  • Pastille Beta / Update : jours de beta restants, ou nouvelle version à installer en un clic.
  • STEMS : progression de la séparation des stems en cours.
  • Contrôleur : le contrôleur reconnu (ou « No controller »).
  • ? : ce manuel. Palette : thème, couleur, taille. Engrenage : toutes les Préférences.

Les decks

La barre du deck
  • KEY (cliquer) : décaler la tonalité en demi-tons ou la caler sur l'autre deck.
  • MASTER : ce deck donne le tempo aux autres. BEAT SYNC : se cale sur le master (tempo et phase). KEY SYNC : prend une tonalité compatible avec le master.
  • Boutons de grille épinglés : les actions de grille que tu as mises sur la barre (en icônes).
  • Menu grille (icône grille) : Set downbeat (bar start) at play head, Shift grid ← / → 10 ms, Shift grid ← / → 1 beat, BPM × 2 / ÷ 2, BPM − / + 0.01, Tap tempo…, Convert to constant grid, verrouiller la grille, Re-analyze (normal / dynamic grid). Glisse une action sur la barre du deck pour l'y épingler, ou coche-la dans Buttons on the deck bar.
  • Menu du deck (⋯) : Instant Double from Deck N (copie l'autre deck à la même position), Create cues from phrases, DRUM SWAP slots…, Set MIX IN / MIX OUT at play head, Clear mix points, Eject, et Load while playing (all decks) pour autoriser ou non le chargement sur un deck qui joue.
Jog, tempo et boutons du deck
  • Jog : BPM au centre ; tourner = pitch bend, en mode vinyle = scratch. 6 / 10 / 16 / W sous le BPM : la plage du fader de tempo.
  • Q quantize, MT master tempo (la tonalité ne bouge pas avec le tempo), SLIP, REV lecture à l'envers, CENSOR (maintenu) : à l'envers puis retour là où le morceau en serait.
  • Fader de tempo : double-clic = remise à zéro.
  • CUE et ▶❚❚ : comme sur un lecteur ; CUE maintenu à l'arrêt = pré-écoute.
  • Stems : FAST / HQ lance la séparation ; VOCAL / INST / BASS / DRUMS coupent ou remettent chaque partie.
  • Boucles : 1/2X, ◀ taille ▶, 2X, IN, OUT, RELOOP. JUMP ◀ ▶ saute de la taille affichée (clic sur JUMP pour la changer). RESET remet le tempo à 0.

Les pads des decks

Les 12 modes (bouton du mode, au-dessus des pads)
  • HOT CUE : pad vide = pose une cue, plein = y saute. Shift+clic = efface. Clic droit sur une cue : Rename…, Color, Delete.
  • PAD FX : un effet tant que le pad est tenu. SLICER : maintenir un pad boucle ce 8ᵉ des 2 mesures en cours, puis la lecture reprend où elle en serait.
  • BEAT JUMP / BEAT LOOP : sauts et boucles de tailles fixes.
  • SAMPLER : les cases du sampler. KEYBOARD : le morceau joué à d'autres hauteurs, comme un clavier. KEY SHIFT : décale la tonalité.
  • STEMS : couper ou isoler les parties. MEMORY CUE : rappeler les memory cues (Shift+clic = effacer). GROOVE : DRUM SWAP, remplace la batterie par des boucles.
  • SEQ CALL : pas encore disponible.
  • PAGE : certains modes ont 16 valeurs, sur 2 pages de 8.

Les formes d'onde

Zoom, déplacement et phrases
  • Glisser pour se déplacer dans le morceau, molette pour zoomer.
  • Clic droit sur une phrase (INTRO, CHORUS, DOWN…) : Change to (changer son nom), Cut the phrase here (au début de mesure le plus proche), Join with the next phrase, déplacer son début, Shift all phrases (← / → 1 mesure ou 1 temps), Back to the analysed phrases.

Mixer et effets

Mixer
  • Par voie : TRIM, HI / MID / LOW, ISO (PART ISOLATOR : les 3 boutons règlent voix, instruments et batterie), COLOR (filtre ou Color FX), casque, fader, crossfader A / THRU / B.
  • Au centre : MASTER, PHONES, CUE/MST (mélange dans le casque) et le type de COLOR FX (FILTER, SPACE, DUB ECHO, NOISE, CRUSH…).
  • Double-clic sur un bouton = valeur par défaut.
Beat FX (bouton FX)
  • Choix de l'effet, ◀ longueur en temps ▶ (AUTO = calé sur le BPM), LEVEL/DEPTH, la voie qui le reçoit (1–4, M master, S sampler), puis ON.

Sampler (16 cases)

Utiliser les cases
  • Case vide : un clic capture la boucle qui joue (seulement les stems audibles). Glisser un morceau dessus pour le charger.
  • Case pleine : un clic la joue ou l'arrête ; molette = volume de la case. Boutons ⤓ enregistrer en WAV, ✎ éditer, ⏏ éjecter.
  • Clic droit : One shot / Loop, Sync to master tempo, Gain, Capture the playing loop here, Save as WAV…, Edit… (découpe, mode, sync, gain), Eject.

PADS : sampler 64 pads, instrument, light show

Les trois modes
  • SAMPLER : 64 pads de sons (batteries, synthés, effets, fichiers, boucles capturées). Clic = joue (Shift = pleine force).
  • INSTRUMENT : la grille devient un clavier. Les pads allumés sont dans la tonalité ; les colorés sont la note de base.
  • SHOW : l'animation de fond couvre toute la grille, chaque pad joue son son et son effet de lumière.
La barre du panneau
  • Kit (liste) et ⋯ : New empty kit, Duplicate this kit, Rename…, Export the kit…, Import a kit…, Add the built-in kits again, Delete.
  • EDIT : un clic sélectionne le pad au lieu de le jouer (Alt+clic aussi). En EDIT, glisse un pad sur un autre pour l'y déplacer.
  • Quantize : les boucles partent tout de suite, au prochain temps ou à la prochaine mesure du master. STOP ALL, VOL.
Le menu d'un pad (clic droit) et l'éditeur
  • Clic droit : Drum, Synth note, DJ effect (riser, impact…), Audio file…, Selected track in the browser, Capture the deck loop here, Copy / Paste, Use as the instrument sound, Clear. Tu peux aussi glisser un fichier audio sur un pad.
  • Éditeur : nom, note, Play (One shot, Hold tant que tenu, Loop, Toggle), Sync et BPM du sample, Choke (les pads d'un même groupe se coupent : charley ouvert / fermé), gain, pitch, couleur, effet de lumière et sa durée.
Le mode INSTRUMENT et les notes infinies
  • Sound : un des 8 synthés, ou un de tes pads joué à toutes les hauteurs.
  • Key : Follow the master track (suit la tonalité du morceau master), sinon note de base et gamme au choix. Layout : dans la gamme ou chromatique.
  • Durée des notes : Held: endless note = la note dure tant que tu restes appuyé, sans fin (choix par défaut) ; Held: the sound fades = elle s'arrête au relâchement ou quand le son s'éteint ; Tap: plays to the end = chaque note joue son son en entier.
Le light show (mode SHOW)
  • Background : Pad colours, Beat pulse, Rainbow, Wave, Spectrum, Rain ou Off. Brightness.
  • Pad colours : Rainbow, By row, Random, By sound. All effects : le même effet sur tous les pads.
  • Couleur et effet d'un seul pad : mode SAMPLER, EDIT, clic sur le pad.
Sur un Launchpad X
  • Reconnu tout seul. Session = SAMPLER, Note = INSTRUMENT, Custom = SHOW, Capture MIDI = capture la boucle du deck dans le premier pad libre.
  • ▲ ▼ : kit précédent / suivant (en INSTRUMENT : octave). ◀ : quantize (en INSTRUMENT : transposer −1) ; ▶ : tout arrêter (en INSTRUMENT : +1).
  • Colonne de droite : SAMPLER = arrête la rangée, INSTRUMENT = choisit le synthé, SHOW = choisit l'animation. Le logo bat la mesure.

Le navigateur

L'arbre à gauche
  • Collection, Tag List (liste de travail), Stems (morceaux déjà séparés), Related Tracks (règles : BPM, tonalité, genre, artiste…), Track Suggestion, puis tes playlists, Intelligent Playlists et historiques.
  • Clic droit sur un dossier ou une playlist : New playlist / folder / intelligent playlist here, Edit conditions… et Freeze into a normal playlist (Intelligent Playlist), Analyze tracks, Export as M3U8…, Find duplicates…, Send to another Reboxed (USB drive)…, Move to, Rename…, Delete.
  • Tag List : Convert to playlist…, Clear Tag List. Historique : Turn into playlist, Delete this history, Delete all histories.
Le menu ⋯ (outils de la bibliothèque)
  • Import a DJ library (XML)… : récupère cues, grilles, tags et playlists d'un autre logiciel. Export collection as XML…
  • Download tracks…, Export to USB for DJ players… (clé pour lecteurs de club).
  • Auto-tag the tracks shown… (genres, titres, artistes via Spotify / Deezer), Clean the names of the tracks shown…, Undo the last auto-tag / clean.
  • Send to / Import from another Reboxed (avec les stems), Find duplicates in the collection…, Analyze all unanalyzed tracks, Find missing files, Move my collection to a USB drive…
Clic droit sur un morceau
  • Load to Deck N, Add to playlist, New playlist from selection…, Add to Tag List.
  • Show related tracks, Show suggestions, Analyze, Create cues from phrases, Separate stems.
  • Rating, Color, Track information… (avec recherche d'infos en ligne), Auto-tag…, Clean names…, Show in Explorer, Remove from collection.
Les colonnes
  • Clic sur un en-tête = trier ; glisser un en-tête = déplacer la colonne ; glisser son bord = largeur.
  • Clic droit sur un en-tête : afficher ou cacher des colonnes (Label, Year, Remixer, Bitrate, My Tag…), Fit all columns to their content, Reset column widths / order.
  • FILTER : filtrer la liste (BPM, tonalité, note, couleur…). La recherche ignore les accents.

Suggestion de morceaux

Track Suggestion
  • Point de départ : Master deck, un deck précis, ou le morceau sélectionné.
  • Keep the energy / Build up / Cool down : garder, monter ou redescendre l'énergie.
  • Le classement mélange le son, la tonalité, le tempo, l'énergie et ce que tu enchaînes d'habitude (tes historiques). Les raisons des premiers choix s'affichent au-dessus de la liste.
  • ✦ ASK GEMINI (optionnel, clé dans Préférences ▸ Library) : reclasse et propose des morceaux à découvrir ; un clic sur l'un d'eux le cherche dans la fenêtre de téléchargement.

Téléchargement

La fenêtre DOWNLOAD
  • Recherche sur YouTube ou SoundCloud, lien collé (ou glissé sur l'appli), playlist Spotify (chaque titre retrouvé sur YouTube), nouvelles sorties des chaînes que tu suis.
  • Les noms sont nettoyés (« Official Video », « Lyrics »…) et les morceaux arrivent analysés dans la collection.

Préférences (engrenage)

Les onglets
  • General : analyse (grille normale ou dynamique), notation des tonalités (8A ou Am), couleurs d'onde, fenêtre.
  • Appearance : thème, couleur d'accent, taille de l'interface.
  • Decks & Mixer : nombre de decks, type de sync, plage de tempo, courbes des faders et du crossfader.
  • Audio : cartes son du master et du casque, 2ᵉ sortie master.
  • Library : dossier de la bibliothèque et des stems, clé USB, Spotify, Discogs, clé Gemini.
  • Stems : modèles, qualité, moteur (processeur ou carte graphique) et Test the engines.
  • Downloads : qualité, dossier, nettoyeur de noms, outils.
  • MIDI : contrôleurs connectés, moniteur MIDI, MIDI learn. Plugins : installer, créer, activer les plugins de contrôleurs.
  • Keyboard : raccourcis (QWERTY / AZERTY), chaque touche se change. About : version, mises à jour, liens.

Raccourcis clavier

Deck 1 / Deck 2 (touches QWERTY ; un clavier AZERTY est détecté tout seul)
  • Play : Z / N · Cue : A / H · Sync : Q / Y · Pitch bend − + : W E / U I
  • Loop in / out / reloop : D F G / K L ; · Loop ½ / ×2 : Shift+D, Shift+G / Shift+K, Shift+;
  • Hot cues A–D : 1–4 / 6–9 (avec Shift : effacer) · Boucles : Ctrl+1–5 / Ctrl+6–0
  • Slip reverse : S / J · Charger le morceau sélectionné : Shift+← / Shift+→ · Rechercher : Ctrl+F · Navigateur plein écran : Espace
  • Tout se change dans Préférences ▸ Keyboard.

Contrôleurs

Brancher et jouer
  • Un contrôleur avec plugin est reconnu au branchement : jogs, pads, mixer, FX, LED, et sa carte son est choisie (Préférences ▸ Audio pour changer).
  • Un bouton de mode de pads sur le contrôleur ouvre la même page à l'écran.
  • Autre matériel MIDI : Préférences ▸ MIDI ▸ MIDI learn. Le moniteur MIDI montre chaque message reçu et la fonction déclenchée.
  • Les plugins de contrôleurs : Préférences ▸ Plugins.
